A bank complaint, answered in 15 seconds. Sent only when a person says so.

Clearline is an open-source reference implementation of an AI agent for a regulated workflow. It reads a customer complaint, investigates the account, checks the bank's policies and Hungarian financial law, and drafts a reply with citations. A complaints officer makes the final call.

Why it is built this way

The process comes first
The agent follows a complaint-handling procedure with deadlines, escalation rules and mandatory content. The model fills steps; it does not invent the process.
People decide
The workflow stops at human review. Approve, edit and reject are recorded with the reviewer and reason, the human oversight the EU AI Act expects.
Measured, not vibed
A golden set of complaints with known outcomes runs in CI. A prompt or model change that lowers decision accuracy, refund accuracy or groundedness does not ship.
Cost is a feature
Cheap models do screening, triage and lookups; a stronger model writes the decision and the letter. Every call's tokens, cost and latency are in the audit log.
Customer data stays in the EU
Each model endpoint declares its region. In live mode the service refuses to start with a non-EU endpoint. Non-EU models are only used on synthetic data.

Stack

Agent
Python, LangGraph with a Postgres checkpointer, function calling, OpenAI-compatible model tiers
Retrieval
PostgreSQL, pgvector, full-text search in Hungarian and English, reciprocal rank fusion, multilingual embeddings run locally
API
FastAPI with server-sent events, Pydantic, audit log in Postgres
Interface
Angular 22 with signals, Optimus UI
Quality
Golden-set evals with an LLM judge and CI thresholds, pytest, ruff, pyright
Delivery
Docker, GitHub Actions, Azure Container Apps
